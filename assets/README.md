## Manual tasks (cannot be automated)

### 1. Set GitHub repo description

Go to https://github.com/EmilHerzberg/honest-factor-research → "About"
(top right) → ✏️ edit → set Description to:

> A reproducible Python framework for auditing stock factor models: detects
> sector mirrors, regime shifts, proxy contamination, and overconfident R².

Add topics (tags): `quant`, `factor-model`, `model-evaluation`,
`trustworthy-ai`, `financial-ml`, `ridge-regression`, `bootstrap`,
`regime-switching`, `us-equities`, `python`, `reproducible-research`.

### 2. Upload social preview to GitHub

Settings → "Options" → "Social preview" → "Upload an image" → upload
[`banner.png`](banner.png).

This is what shows up when the repo is shared on LinkedIn / Twitter /
Slack — without this, GitHub falls back to a generic Octocat preview
that looks unprofessional.

## Original visual specifications (for reference)

### 1. Hero banner — `assets/banner.png`

**Purpose:** GitHub social preview + top of README.

**Dimensions:** 1280 × 640 px (standard GitHub social preview size).

**Composition:**
- **Background:** dark navy or deep slate, with subtle grid lines
  (financial-chart aesthetic)
- **Headline (top):** **"Honest Factor Research"** in a clean modern
  sans-serif, white or near-white
- **Subtitle (below):** "A reproducible model-audit framework for stock
  factor models." (lighter weight, slightly smaller)
- **Tagline (bottom right):** "Separating real explanation from sector
  mirrors, regime shifts, and overconfident R²." (smaller, more muted)
- **Optional visual element:** a subtle abstract chart line or
  scatter-plot motif suggesting decomposition or stratification —
  *not* a meme rocket, *not* a green-up-arrow, *not* a Bull/Bear logo.

**Avoid:** dollar signs, Wall Street clichés, AI buzzword stock photos,
hard-edged gradients, anything that signals "crypto blog."

**Aim for:** the visual aesthetic of an academic finance paper crossed
with a high-end ML research blog post (Distill.pub, Anthropic blog, OpenAI blog).

### 2. Trust-Stratified Decomposition explainer — `assets/trust_decomposition.png`

**Purpose:** illustrate the central concept (decomposition into DIRECT /
STATISTICAL / DERIVED + idiosyncratic).

**Composition:**
- **Side-by-side comparison:**
  - **Left:** "Traditional R²" — a single horizontal bar labeled
    "R² = 0.85" with "Explained" in one color and "Unexplained" in
    another. A short caption: *"What you usually see."*
  - **Right:** "Honest decomposition" — same width, but the
    "explained" portion is split into 3 stacked segments:
    - DIRECT (deep green)
    - + STATISTICAL (medium blue)
    - + DERIVED / mirror-suspect (warning orange)
    - "Unexplained / idiosyncratic" still in grey
  - Caption on the right side: *"How much of that R² can we honestly defend?"*

**Use case:** central image in the README "What this project does"
section. Should communicate the entire elevator pitch visually in one
glance.

### 3. Architecture diagram — `assets/architecture.png`

**Purpose:** quick pipeline overview for technical reviewers.

**Composition:**
- Left-to-right flow diagram, professional/restrained styling
- Boxes for each major stage:
  - "Market Data (yfinance + NASDAQ-screener)" →
  - "Log Returns" →
  - "Factor Catalog (28 factors, YAML)" →
  - "Sequential Gram-Schmidt Residualization" →
  - "Rolling RidgeCV (252-day window)" →
  - Three parallel outputs:
    - "Trust-Stratified R² (DIRECT / STAT / DERIVED)"
    - "Block-Bootstrap CI (Politis-Romano)"
    - "VIX-Stratified Regime Betas"
  - All three feed into → "Reports & CSVs"

**Optional but nice:** small annotations on the arrows showing what
flows (e.g. "wide log-returns", "(asset, factor, beta) triples").

**Alternative:** the README already includes a Mermaid version of this
diagram which renders inline on GitHub. The PNG version would only be
needed for embedding in slides or external presentations. Currently the
Mermaid version is sufficient.

### 4. Social preview — `assets/social_preview.png`

**Purpose:** the image that shows up when you share the GitHub repo on
LinkedIn / Twitter / Slack.

**Dimensions:** GitHub uses 1280 × 640 px for social previews.

**Composition:** could be identical to the hero banner, or a slightly
different aspect-ratio crop emphasizing the headline.

**Configuration:** once uploaded, go to GitHub repo Settings →
"Social preview" → "Upload an image" → upload this file.

## Style guide

For any visual added to this directory:

- **Color palette:** prefer dark backgrounds with bright accent colors
  (matches the "serious finance/ML research" aesthetic)
- **Typography:** clean modern sans-serif. Avoid serif-display fonts
  that read as "academic textbook"
- **No clichés:** no rockets, no money bags, no robot-shaking-hands-with-human,
  no chart-going-up-and-to-the-right hero shots
- **Minimal text:** if you can convey the idea with one chart and one
  sentence, that's better than a flowchart with 8 labels
